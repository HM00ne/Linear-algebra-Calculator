# Linear Algebra Calculator
!Run vector_app.py for the application!
WARNING:This project is yet to be complete, new tabs of linear algebra classes will be added in future update

A polished desktop application (Tkinter + Matplotlib) that turns abstract linear-algebra operations into living geometry.

Watch vectors grow, stretch, rotate and project in real time while the full algebraic working is written out step-by-step and the exact same calculation is shown as runnable Python code.

## Features

- **10 interactive topics**
  - Scalar × Vector
  - Dot Product & properties
  - Cauchy–Schwarz inequality
  - Vector Length & unit vectors
  - Hadamard (element-wise) product
  - Row & Column vectors (inner / outer product)
  - Product notations side-by-side
  - Everything between two vectors (sum, difference, distance, angle, cross product…)
  - Law of Cosines
  - Complex numbers as vectors

- **Live geometric visualisation**
  - Smooth 2D / 3D plots with drag-to-pan, scroll-to-zoom and double-click reset
  - Animated transitions when values change
  - Optional motion trails, projections, angles and component guides

- **Step-by-step algebra**
  - Beautiful typeset working with real vectors, matrices, roots and angles
  - “Replay steps” animation that writes the calculation on the board

- **Generated Python**
  - Instant, runnable NumPy code for the current numbers
  - One-click Run & Copy

- **Polish**
  - Five colour themes (Classic Light, Midnight, Forest, Sepia, Violet Night)
  - Animated splash screen
  - High-DPI / scaled-display support
  - Configurable animation speed (Relaxed → Off)
  - Keyboard shortcuts and smooth window resizing
